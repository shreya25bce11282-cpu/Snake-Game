# Snake-Game
🐍 Snake Game 

What is this?
A classic Snake game built with JavaScript, CSS and HTML5 Canvas.
Control the snake with your arrow keys, eat the red food, and try to get the highest score!

Features
Simple grid-based movement

Keyboard controls (arrow keys)

Score tracking

Game over and restart

How to Play
Open snake.html in your browser

Use the arrow keys to move the snake

Eat the red food to grow and score points

Avoid hitting the walls or your own tail

Files
snake.html — Main HTML file

snake.js — Game logic and drawing code

Why I made this
I built this project to learn about JavaScript, canvas drawing, and basic game logic.
It’s a great starting point for anyone new to coding games!
