# Snake GAme

🐍 Snake Game (HTML, CSS & JavaScript)
Overview
A classic Snake game built using HTML, CSS, and JavaScript.
The game features a responsive design and custom styles for a clean, modern look.

Features
Playable in any modern browser

Keyboard controls (arrow keys)

Score tracking and game over screen

Custom CSS for layout, colors, and responsive design

How to Play
Open snake.html in your browser

Use the arrow keys to control the snake

Eat the red food to grow and increase your score

Avoid running into the walls or your own tail

File Structure
snake.html — Main HTML file

snake.js — Game logic and animation

style.css — All custom styles and layout
